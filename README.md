# Smart Crop Rotation Management System

## About the Project
The Smart Crop Rotation Management System is a beginner-friendly website designed to provide information about crop rotation, crop recommendations, seasonal planning and soil health.

## Objectives
- Provide crop rotation information.
- Suggest suitable next crops.
- Display seasonal crop information.
- Explain the importance of soil health.
- Promote sustainable agriculture.

## Technologies Used
- HTML
- CSS
- JavaScript

## Main Features
1. Home Page
2. Popular Crops
3. Crop Recommendation
4. Seasonal Planner
5. Crop Rotation History
6. Soil Health Information
7. Contact Form
8. About Project

## Project Structure
- index.html - Website structure
- style.css - Website design
- script.js - Website functionality

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in Google Chrome.
